# Programming Principles — Tomasz (45, MWF Lifter)

Distilled from the iterative design of the 10-Week Strength & Conditioning Plan. Use these as constraints and defaults when writing any future training block.

---

## Athlete Constants

| | |
|---|---|
| **Age** | 45 |
| **Injuries** | Tennis elbow (lateral epicondylalgia), goose foot (pes anserinus) |
| **Schedule** | MWF lifting, Tue/Thu active recovery, Sat/Sun rest |
| **Session cap** | 60 minutes including warm-up, ramp, and cooldown |

---

## 1. Injury Rules (Non-Negotiable)

### Elbow
- Hook grip for all cleans.
- Neutral grips for all pressing and pulling accessories. Straight-bar bench is the **only** non-neutral press allowed.
- Ring pull-ups over fixed-bar — rings allow natural wrist rotation.
- Plyo push-ups preferred over med-ball throws for power primer.
- Row (erg) only if elbow is fully symptom-free; damper ≤ 4, loose hook grip.

### Knee (Goose Foot)
- Tripod foot pressure, knees tracking over toes on all squats.
- Box squat is always a lower-intensity accessory, never a primary squat.
- Unilateral work: slow eccentric, perfect tracking, submaximal load.
- Single-leg calf raises belong in every program for ankle/knee stability.

### Shoulder
- Vertical pressing must stay light and clean — landmine press or similar, never heavy overhead.
- Face pulls, banded external rotation, and band pull-aparts are permanent fixtures, not optional accessories.

### Pain Scale
- Pain ≤ 3/10 during training.
- Symptoms must return to baseline within 24 hours.
- If not: reduce volume 20–30% next session.
- Optional accessories only when previous session elbow pain was ≤ 2/10 **and** next-day recovery is 100%.

---

## 2. Session Architecture

### 60-Minute Rule
All MWF sessions must fit within 60 minutes including warm-up, session-specific ramp, working sets, and cooldown. To enforce this:
- Barbell work first; trunk and shoulder-balance work shifts to Tue/Thu.
- Friday assistance work (exercise D) is **time-permitting** — complete A–C first.
- Supersets only for low-skill accessories, never for main lifts.

### Warm-Up Structure (Every MWF)
1. **General** — 3–5 min light Bike or SkiErg.
2. **Joint prep** — glute bridges, single-leg RDLs, lateral band walks, wrist rolls, eccentric wrist extensions, hollow body hold.
3. **Session ramp** — day-specific drills progressing from mobility → pattern rehearsal → neural primers. No fatigue, no failure.

### Cooldown (Every MWF)
- 3–5 min easy aerobic spin (also serves as Friday's conditioning block).
- Eccentric wrist extensions + forearm stretch.
- Hip flexor / pigeon / quad stretch.
- Pec stretch + band pull-aparts.

---

## 3. Weekly Structure — HLM (Heavy–Light–Medium)

| Day | Stress | Role |
|-----|--------|------|
| Monday | **Light** (lower body) | Upper-body primary (bench), compression skills, vertical pull |
| Wednesday | **Medium** | Olympic lift + moderate squat (box squat), pike compression |
| Friday | **Heavy** | Heavy squat, clean variation primer, secondary bench, hinge/unilateral |
| Tuesday | Recovery | Cardio (harder rowing day), trunk work (plank + Pallof), compression micro-dose |
| Thursday | Recovery | Cardio (easy rowing day), shoulder balance (face pulls + landmine press), structural circuit |

This pattern is the single most effective structural choice for masters lifters. Wednesday squat loads must stay **clearly below** Friday squat loads at all times.

---

## 4. Periodization Defaults

### Phase Structure
| Phase | Duration | Rep Range | RPE Ceiling | Tempo |
|-------|----------|-----------|-------------|-------|
| Accumulation | ~4 weeks | 6–8 | 6–7 | Controlled eccentrics (2 sec bench, 1 sec squat pause) |
| Intensification | ~4 weeks | 3–5 | 7–8 | Normal bar speed |
| Deload | 1 week | 5 (reduced sets) | 5–6 | Normal |
| Realization | 1 week | 3 (heavier) | 8 (cap) | Normal |

### Autoregulation
- Listed percentages are **ceilings**, not forced targets.
- If bar speed drops, positions break, or pain rises → reduce load 2.5–5% or cut 1 set.
- Every deload week must have an explicit RPE target — never leave it undefined.

### Load Progression Pattern
- Benchmark: work from ~65% to ~85% of training max across the block.
- Reps decrease as intensity increases (e.g. 4×8 → 4×3).
- Week-to-week jumps: 2.5% (press), 2.5–5% (squat/pull).

---

## 5. Volume & Frequency Rules

### Push : Pull Ratio
Aim for roughly **2:3 push-to-pull** by set count. Pulls include rows, pull-ups, face pulls. This protects shoulder health long-term.

### Secondary Dose Principle
Each primary pattern appears **twice per week**: once as the main lift, once as a lighter variation on a different day. The second dose is for skill and frequency, never intensity.
- Friday clean variation is a **technical primer** — stop the set if turnover slows.
- Friday bench variation is a **lighter barbell dose** — stay 2–3 reps shy of failure.

### Alternating Assistance
Don't stack posterior chain stress. Alternate by week:
- **Odd weeks:** RDLs (hinge dominant)
- **Even weeks:** DB step-ups (unilateral/knee dominant)

This spreads tissue stress across training weeks.

### Friday Priority Order
Always: Clean primer → Squat → Bench variation → Assistance (time-permitting). This ordering preserves performance on the exercises that matter most.

---

## 6. Olympic Lifting Rules

- Weeks 1–2: start from the hang to rebuild timing.
- Weeks 3+: transition to floor.
- Intensification: shift to doubles (fewer reps, better quality).
- Friday variations: light, fast, positional — tall cleans, high-hang, low-hang, pause variants.
- If catches get sloppy or slow → convert remaining sets to clean pulls.
- Clean pull loads scale off the clean max (80–85%), not the deadlift.
- Total Olympic lift volume should taper: ~12 reps/session → ~10 → ~8 across phases.

---

## 7. Structural Balance (Permanent)

These are not optional accessories — they are **permanent maintenance work** that prevents chronic issues.

### Thursday Structural Circuit (2 rounds, ~7 min)
- Single-leg calf raise: 12/leg
- Side plank: 20 sec/side (accumulation) → 30 sec/side (intensification)
- Banded external rotation: 12/side

### Tuesday Trunk Work
- Front plank + Pallof press superset — anti-extension and anti-rotation in one block.
- This is the only dedicated trunk training day; keep it low-fatigue.

### Power Primer (Monday, ~2 min)
- 3×3 plyo push-ups before bench. Primes nervous system, improves bar speed.
- Substitute med-ball chest pass if elbow flares (pain > 2/10).

### Deload/Realization Adjustments
- Deload: structural circuit → 1 round; trunk work → lighter.
- Realization: structural circuit → omit entirely; trunk work → minimal.

---

## 8. Compression Skills (L-Sit / Pike)

### L-Sit Progression Landmarks
1. Tucked hold → 2. Alternating single-leg extensions → 3. One leg out → 4. Full L-sit attempt.

Advance only when all sets are held with locked elbows, depressed shoulders, no lumbar collapse, and no shaking.

### Pike Pulse Position Milestones
1. Hands beside knees, hips just clearing floor.
2. Hands beside mid-shin, consistent lift.
3. Full hip extension, heels elevated, no peak collapse.

Progress by **lift height and peak holds**, not just rep count.

### Micro-Dosing (Tue/Thu)
Short compression work (10–20s holds, 6–10 compression lifts) on recovery days provides frequency without fatigue.

---

## 9. Cardio Integration

### Default Modalities
- Bike and SkiErg are always acceptable.
- Rowing only when elbow and knee are fully symptom-free.

### Weekly Pattern
- **Tuesday:** harder cardio day (intervals, distance pieces).
- **Thursday:** lower-fatigue aerobic/technique day.
- **Weeks 9–10:** easy aerobic only (15–30 min), no structured intervals.

### Rowing-Specific Rules
- Stroke order: legs → body → arms (drive), arms → body → legs (recovery).
- Watch split/500m — stay consistent, don't sprint the first piece.
- Damper ≤ 4, loose hook grip.

### Timing Conflicts
Never schedule a max-effort cardio test (2,000m row, etc.) the day before a peak lifting session. If Wednesday or Friday carries ≥ 80% loads, Tuesday cardio must be moderate or easy.

---

## 10. Recovery & Weekend

- **Saturday:** full rest or easy walk. No loaded training.
- **Sunday:** optional easy bike/SkiErg + stretching. Use as a body-check day — note lingering symptoms before Monday.
- If Saturday pain is above baseline → apply Pain Scale rule to Monday.

---

## 11. Program Transition Rules

### Block-to-Block Handoff
- If the outgoing block ends with a taper/bridge, the new block can start at listed loads.
- If the outgoing block ends abruptly, reduce Week 1 loads by 5 kg (squat) or 2.5–5 kg (press) and rebuild.
- Ring pull-ups: stay bodyweight for the first 6 weeks of any new block unless elbows are fully calm.
- Cleans: if catches feel inconsistent, start at ~60% and rebuild to listed loads by Week 2.

### Annual Structure
Programs should fit into a repeating wave:
1. **Accumulation** — volume, tissue prep, skill building.
2. **Intensification** — heavier loads, lower reps, sharper technique.
3. **Realization / Testing** — peak effort week(s).
4. **Maintenance / Athletic** — lower stress, broader movement, active recovery.

Each block builds on the previous one. Avoid identical back-to-back blocks to prevent stagnation and overuse.

---

## 12. Document Standards

When writing a new program document:
- State progression, pike, and L-sit rules **once** in a rules section, then reference them by name — don't repeat the full text in every week.
- Cardio lines should be brief: "Row — Week N *(Rowing table)*; Bike/SkiErg if symptomatic."
- Cooldown is in the rules — don't restate it every Friday.
- Mark all optional/time-permitting work explicitly.
- Include a quick-reference load progression table at the end.
- Every phase needs explicit RPE targets in the autoregulation rule — no gaps.
