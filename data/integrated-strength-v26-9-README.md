# Integrated Strength Program V26.9 - Longevity Update

## Overview

The 20-Week Integrated Strength Program (V26.9) is a comprehensive pulling-focused training program optimized for the 40+ athlete, emphasizing Volume Management and Joint Longevity.

## Files

- **integrated-strength-v26-9.json** - Complete consolidated program (121 KB)
- **integrated-strength-block[1-6].json** - Individual block files for reference

## Program Structure

### Duration: 21 Weeks (6 Training Blocks)

1. **Block 1: Foundation** (Weeks 1-4)
   - Establish volume baseline (36-40 reps)
   - Build connective tissue tolerance
   - Skills: Crow Stand, HSPU Volume

2. **Block 2: Intensification** (Weeks 5-8)
   - Transition to EMOM density training
   - Increase pushing capacity
   - Skills: Tuck Planche, PPPU Lean

3. **Block 3: Neutral Grip Integration** (Weeks 9-12)
   - Protect distal biceps tendon
   - Develop unilateral stability via Cluster sets
   - Strict connective tissue deload (Week 12)

4. **Block 4: Accumulation** (Weeks 13-16)
   - Peak absolute strength testing
   - AMRAP progressions
   - Core challenge (Dragon Flags/V-Ups)

5. **Block 5: Peak & Taper** (Weeks 17-19)
   - Neural sharpening for test week
   - Archer Negatives introduction
   - Full deload (Week 19)

6. **Block 6: Test Week & Reload** (Weeks 20-21)
   - Week 20: Performance testing
   - Week 21: Post-program reload (60% volume)

## Key Features

### Safety-First Programming

- **Early Warning System**: Automatic 30% volume reduction for injury signals
- **Dip Governor Rule**: Shoulder protection protocol
- **Grip Saver Protocol**: Ground-based core work on Day 5
- **Volume Cap**: Strict 36-40 weekly pull-up reps
- **Structured Deloads**: Weeks 4, 8, 12, 16, 19

### Training Principles

1. **Double Progression Rule**: Earn weight increases by hitting top rep range
2. **Standard Tempo**: 2-1-1-0 for accessories unless specified
3. **Rep-Before-Load**: Quality reps before adding weight
4. **Cold Start Protocol**: 5-min rower warmup before Day 1 & 5
5. **Global Tendon Prep**: Band work + scap pulls + passive hangs

## Target Audience

- **Primary**: 40+ athletes seeking sustainable strength gains
- **Level**: Advanced (comfortable with pull-ups and dips)
- **Goals**: Elite pulling strength, joint health, longevity

## Program Rules

### Volume Management
- Weekly pull-up reps: 36-40 (strictly enforced)
- Day 5 accessories: 10-minute hard cap
- Unilateral leg work: Alternating EMOM

### Safety Protocols
- Monitor elbow tightness (>24hr = red flag)
- Sharp pain = immediate volume reduction
- Grip fatigue = early warning
- Shoulder pinch = switch exercises

### Block-Specific Rules
- **Block 3**: Use same neutral grip implement throughout
- **Block 4**: Dip Governor auto-regulation
- **Block 12**: NO dead hangs, NO weighted core
